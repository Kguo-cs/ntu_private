## 1. 地图创建、导入与自定义

### 1.1 地图创建流程和格式

本模型使用waymo场景格式，参考[waymo网站](https://waymo.com/open/download/). 地图中元素类型[参考](https://github.com/waymo-research/waymo-open-dataset/blob/master/src/waymo_open_dataset/protos/map.proto)


创建过程：
1. 从[waymo数据下载](https://waymo.com/open/download/)的waymo_open_dataset_motion_v_1_3_0/uncompressed/scenario的training，validation下载数据。

2. 将[config.yaml](config.yaml)中的data_path改成下载数据的文件夹

## 2. 场景元素管理（增加、编辑、删除）

### 2.2 增加元素

由于目前场景中无静态物体，所以仅支持静态物体增加，不支持删除和编辑。通过修改[config.yaml](config.yaml) 中的static_object的add属性来制定增加的物体位置和形状。

地图元素的增加，通过修改[config.yaml](config.yaml) 中的map_object的add属性来制定增加的地图元素的id，类型，位置（用一条折线表示）。

### 2.3 编辑元素

编辑地图元素可以通过增加相同id的地图元素，来实现代替。

### 2.4 删除元素

通过修改[config.yaml](config.yaml) 中的map_object的remove属性来制定删除的地图元素的id。

## 3. 交通参与者行为与交互规则配置

### 3.1 行为模式设定

支持以下行为模式：

| 模式    | 描述              |
| ----- | --------------- |
| 静止    | 物体保持原地不动        |
| 巡航    | 沿预设轨迹移动         |
| 路径规划  | 实时调用路径规划器自动驾驶   |
| 自定义脚本 | 用户自定义Python行为脚本 |

* 通过选择交通参与者 →「行为配置」可进入设置面板

### 3.2 速度与轨迹设置

* 可设置最大/最小速度、加速度、减速度
* 支持手动绘制轨迹或导入CSV轨迹点文件
* 可绑定至地图参考线或车道中心线

### 3.3 交通信号规则绑定

* 支持与红绿灯、Stop Sign、Yield Sign 等交互
* 在行为编辑界面可设置：

  * 红灯是否停车
  * 是否遵循右转让行/直行优先规则
* 车辆感知范围可调，以模拟不同驾驶策略

## 4. 自车及传感器参数配置指南

### 4.1 自车定义

* 选择「自车」对象，进入参数配置面板
* 支持设置：

  * 车辆模型（轿车、SUV、卡车）
  * 尺寸（长宽高）
  * 动态约束（转向半径、最大加速度）

### 4.2 传感器类型支持

| 类型   | 支持参数           |
| ---- | -------------- |
| 相机   | 内参矩阵、外参（位置与姿态） |
| 激光雷达 | 点云频率、视场角、分辨率   |
| 雷达   | 探测距离、水平/垂直视角   |
| IMU  | 噪声模型、频率        |

### 4.3 相机内外参数设置

#### 内参调整：

* 输入焦距 `fx`, `fy`，主点坐标 `cx`, `cy`
* 支持畸变参数 `k1, k2, p1, p2`（可选）

#### 外参设置：

* 通过矩阵 `[R | T]` 或直接输入 `xyz + rpy` 设置位置姿态
* 可从标定工具导入 `.yaml` 或 `.json` 相机参数文件

### 4.4 多传感器联合布局

* 点击「添加传感器」，选择参考车体坐标系挂载
* 支持多相机拼接视图设置（FOV、重叠区域）
* 系统支持自动检查盲区及视场重叠

## 附录

### 常用文件格式说明

| 类型   | 扩展名              | 描述          |
| ---- | ---------------- | ----------- |
| 地图数据 | `.json`, `.xodr` | 地图结构及元信息    |
| 行为脚本 | `.py`            | 用户自定义行为控制脚本 |
| 轨迹数据 | `.csv`, `.npy`   | 交通参与者轨迹文件   |
| 相机参数 | `.yaml`, `.json` | 相机内外参配置文件   |

### 快捷键一览（GUI模式）

* `Ctrl + S`：保存地图
* `Ctrl + Z`：撤销上一步操作
* `Del`：删除选中元素
* `Space`：播放/暂停仿真
