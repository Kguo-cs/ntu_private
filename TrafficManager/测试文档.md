## 3. 性能指标测试

### 3.1 测试方案

在不同模块激活状态下进行冷启动与运行时资源监控，指标包括：

* **CPU使用率**
* **GPU使用率**
* **内存占用**
* **仿真帧率（FPS）**

### 3.2 各模块资源占用表

| 测试模块  | 状态         | CPU占用 (%) | GPU占用 (%) | 内存占用 (GB) | 帧率 (FPS) | 备注         |
| ----- | ---------- | --------- | --------- | --------- | -------- | ---------- |
| 空载启动  | 无场景加载      | 3.1       | 0.0       | 0.6       | --       | 启动时间 1.2 秒 |
| 地图加载  | 1km 城市地图   | 17.4      | 4.1       | 1.8       | 60       | 结构复杂场景     |
| 场景运行  | 3辆车 + 10物体 | 29.5      | 9.2       | 3.5       | 58       | 动态行为中等复杂度  |
| 多相机渲染 | 3视角        | 38.0      | 37.2      | 4.8       | 45       | 帧率下降明显     |
| 高密度仿真 | 10辆车+信号灯   | 55.2      | 58.7      | 6.3       | 29       | GPU成主瓶颈    |
| 轨迹导出  | 10秒/帧率=60  | 6.4       | 1.0       | 0.9       | --       | I/O 写入正常   |

## 4. 性能瓶颈分析与优化建议

| 模块     | 性能瓶颈描述          | 建议优化方案                    |
| ------ | --------------- | ------------------------- |
| 多相机渲染  | GPU占用高，FPS下降明显  | 支持视图降采样渲染、动态FOV裁剪         |
| 动态交通仿真 | 大量对象导致CPU线程调度瓶颈 | 使用多线程仿真器、简化行为建模逻辑         |
| 地图解析   | 导入超大地图时内存峰值高    | 使用增量解析、延迟加载结构组件           |
| 数据导出   | 导出帧数大时IO写入变慢    | 引入异步写入与批量缓存               |
| 场景编辑器  | GUI在高分辨率屏幕下卡顿   | UI 渲染线程与仿真线程解耦，提高事件驱动响应效率 |
