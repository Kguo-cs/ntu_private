## 数据与解释

CPU时间分桶检查中，四组low-t位置归一化MSE都约0.003，但high-t仍约0.50–0.66；high-t heading MAE约33–38度。pos_mse32的high-t位置误差比anchor低约24%，但heading MAE只略改善。它说明低噪声重建已容易，高噪声地图条件建模仍不足；不能用训练loss直接预测生成JSD。

将geo_mse32的width weight1降为0.5得到balanced32，width JSD1.268→6.723，length1.435→5.426；直方图近似width均值2.123→2.063m（GT2.163m），length均值4.785→4.632m（GT4.892m）。width标准差反而更接近GT，因此这里主要显示均值/bin质量移动与分量耦合，不能简单断言是方差塌缩。

所有组on-road覆盖仍低于GT99.4%；lat/angle只统计on-road车辆，score必须与覆盖共同看。准备好的variantJSON包含未测试方案，不能据它统计训练次数。时间分桶probe的heading radius取自强制单位圆后的输出，不能据radius=1排除原始atan2输入很小的问题。
